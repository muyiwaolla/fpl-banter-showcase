# Product Screenshots

This directory is reserved for curated screenshots of the live FPL Banter product.

Planned examples:

- League dashboard
- Live standings
- Banter statistics
- Monthly winners / MOTM
- Mobile experience
- League onboarding

Only screenshots suitable for a public portfolio should be added here.

Avoid uploading:

- private user information
- email addresses
- access tokens
- admin-only operational data
- environment configuration
- anything that reveals production secrets

The goal is to demonstrate product quality and engineering outcomes without exposing sensitive implementation details.
